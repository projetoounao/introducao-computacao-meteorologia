# Modelo de README — Repositório de Disciplina

**Estado:** primeira versão em validação  
**Origem:** disciplina Introdução à Computação — Bacharelado em Meteorologia/UFCG  
**Finalidade:** servir como modelo para futuros repositórios de disciplinas, cursos, oficinas, estudos orientados e cadernos acadêmicos.  

## 1. Identificação da disciplina

Preencher com os dados acadêmicos básicos.

```text
Nome da disciplina:
Código, se houver:
Curso:
Instituição:
Unidade acadêmica:
Professor(a):
Monitores(as), se houver:
Período/semestre:
Carga horária, se aplicável:
Modalidade: presencial / remota / híbrida
Status do repositório: público / privado / em curadoria
```

## 2. Finalidade do repositório

Explicar por que o repositório existe.

Exemplo:

```text
Este repositório reúne registros, projetos, protótipos, anotações autorais, exercícios selecionados e documentação pública curada produzidos no contexto da disciplina.
```

Distinguir:

```text
repositório público curado ≠ pasta completa de trabalho
GitHub ≠ acervo bruto
Drive/local ≠ publicação automática
```

## 3. Fonte material preservada

Indicar onde estão os arquivos materiais da disciplina, quando houver uma pasta local ou no Drive.

```text
Pasta-base de trabalho:
G:\Meu Drive\...

Status:
fonte material acadêmica reservada
```

Regra:

```text
A pasta material preserva arquivos brutos, materiais recebidos, versões de trabalho e documentos reservados.
O repositório público apresenta apenas a versão curada, documentada e autorizada para acompanhamento.
```

## 4. Ementa e objetivos

### 4.1 Ementa oficial

Registrar a fonte da ementa.

```text
Fonte:
Status de reprodução:
- pública/oficial
- autorizada
- somente referência
- não reproduzir integralmente
```

Regra recomendada:

```text
Preferir link ou referência à ementa oficial.
Reproduzir integralmente apenas se a fonte for pública, oficial ou autorizada.
```

### 4.2 Síntese autoral da ementa

Escrever, com palavras próprias, uma síntese dos temas principais.

```text
Nesta disciplina, foram estudados temas como ...
```

### 4.3 Objetivos oficiais

Registrar apenas se houver autorização ou fonte pública.

### 4.4 Meu objetivo ao cursar a disciplina

Campo autoral.

```text
Meu objetivo nesta disciplina é ...
```

## 5. Conteúdos

### 5.1 Conteúdos oficiais

Listar os tópicos oficiais da disciplina, quando puderem ser registrados.

```text
- tópico 1
- tópico 2
- tópico 3
```

### 5.2 Meu recorte de estudo

Registrar os conteúdos selecionados pela estudante para aprofundamento.

```text
Conteúdos que selecionei para estudar com mais atenção:
- ...
- ...
```

Este campo é diferente da ementa oficial. Ele registra a trajetória autoral de estudo.

### 5.3 Conceitos a retomar

```text
- conceito ainda frágil
- tema a revisar
- dúvida persistente
```

## 6. Materiais da disciplina

Tabela recomendada:

| Material | Autor/instituição | Origem | Uso no curso | Pode ser publicado? | Ação no repositório |
|---|---|---|---|---|---|
| Nome do material | Autor | aula / site / livro / professor | leitura / exercício / referência | sim / não / verificar | link / referência / não publicar |

Regra:

```text
Material recebido em aula não deve ser republicado automaticamente.
Slides, PDFs, listas e apostilas de professores exigem autorização ou licença clara para publicação.
```

## 7. Direitos, permissões e proveniência

Criar ou apontar para um arquivo específico:

```text
RIGHTS_AND_PROVENANCE.md
```

Campos mínimos:

```text
Material:
Autor/instituição:
Origem:
Condição de uso:
Redistribuição autorizada?: sim / não / verificar
Ação adotada:
Observações:
```

Política geral:

| Tipo de material | GitHub público |
|---|---|
| Nome da disciplina, código, professor, semestre | sim |
| Referência bibliográfica | sim |
| Link para material oficial | sim |
| Síntese autoral da ementa | sim |
| Ementa oficial integral | apenas se pública/oficial/autorizada |
| Anotações próprias | sim, após revisão |
| Soluções próprias | sim, com cuidado em relação ao enunciado-fonte |
| Lista completa do professor | não, sem autorização |
| Slides do professor | não, sem autorização |
| Apostila ou PDF recebido em aula | não, sem autorização |
| Código próprio | sim, com licença escolhida |
| Código de terceiros | conforme licença original |

## 17. Critérios antes de publicar

Checklist:

- [ ] O material é autoral ou está autorizado?
- [ ] A fonte está indicada?
- [ ] Há dados pessoais?
- [ ] Há material de professor/instituição sem autorização?
- [ ] Há conteúdo de cliente ou parceiro?
- [ ] Há caminhos locais que não deveriam aparecer?
- [ ] A licença está clara?
- [ ] O que é oficial está separado do que é síntese autoral?
- [ ] O que é estudo pessoal está separado do que é entrega acadêmica?
- [ ] As pendências estão visíveis?

## 18. Princípio geral

```text
O repositório de disciplina não deve ser uma cópia do curso.
Ele deve documentar a trajetória autoral de estudo, os projetos desenvolvidos, as ferramentas usadas, as referências mobilizadas e as condições de uso dos materiais.
```
