Este repositório funciona como a **primeira aplicação pública** do modelo institucional da MC² para documentação de disciplinas, cursos, oficinas e cadernos de estudo.

O modelo mestre fica no repositório institucional da MC²:

```text

Materiais de terceiros, arquivos brutos, documentos internos da MC², dados pessoais, arquivos de clientes, PDFs de aula e demais fontes reservadas devem permanecer fora do repositório público, salvo curadoria e autorização específica.

```text

GitHub público apresenta a versão curada para acompanhamento e avaliação.
```
